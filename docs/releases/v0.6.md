# Release v0.6

## Problem addressed

v0.5 gave operators a Helvetia ops workspace and Act-as scoped reads, but `/ask` still answered mostly from policy text. Case questions such as “why is this transfer stuck?” needed structured client facts without inventing tickets, transfers, or complaint threads.

## User-visible capability

- Bounded **agent workflow** for `/ask`: classify → (optional) select tools → run tools → rewrite → generate, with a hard step limit
- **Read-only client tools** used when a client is in dock context:
  - Profile / KYC
  - Account restrictions
  - Recent / pending transactions
  - Open service requests
  - Interaction history
- **Bounded tool selection** (allowlist, ≤3 tools): heuristics + LLM; soft profile fallback only if selection fails
- **Case-triage answers**: lead with concrete book facts; empty-book honesty (no invented pending transfers, AML cases, or email threads)
- **Evidence chips** on assistant replies (KYC, restrictions, pending txns, open SRs, interactions)
- Ops badge when a client is selected on the dock

## Architecture changes

- Package rename: `app/assistant/` → `app/agent/`
- Explicit workflow: `state.py`, `routing.py`, `nodes/`, `orchestrator.py` runner
- Tool layer under `app/tools/` with typed inputs, Act-as checks, timeouts, structured errors
- `AskResponse.evidence` for structured chips
- Architecture docs updated for select/run tool path

Incremental tags on the feature branch: `v0.61` (rename) → `v0.62` (workflow) → `v0.63`–`v0.67` (tools) → `v0.68` (selection) → `v0.69` (interactions).

## Validation performed

- Unit tests for tools, facts/evidence, tool selection, and workflow routing
- Local Compose API rebuilds after backend changes; targeted pytest green

## Known limitations

- No `get_account_summary` / holdings snapshot tool yet (portfolio enquiry scenarios still thin)
- Policy retrieval is not wrapped as a separate `search_internal_policies` tool (still via rewrite → generate)
- Demo Act-as is still not full authentication or enterprise RBAC
- No write actions, email draft/approve/send, Langfuse, or MCP
- Hosted promote (`dev` → `main` / Render / Vercel) remains a separate deploy step
