# KYC Refresh Policy (superseded)

## Purpose

This legacy policy defined periodic know-your-customer refresh cycles for Helvetia Private Bank AG relationships.

## Refresh cycle (legacy)

- Standard risk clients: refresh every **36 months**
- Higher-risk clients: refresh every **24 months**
- Triggered refresh only when Compliance issued a written notice

## Status

This document is **superseded**. Do not use it for operational decisions. The active KYC refresh rules are in **POL-KYC-002**.

Kept in the knowledge base so retrieval evaluation can detect superseded-policy traps and confirm default search returns active documents only.
